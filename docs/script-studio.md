# Script Studio

**Script Studio** is the writing and recording surface for your reel scripts. It's where the ideas and competitor teardowns from elsewhere in KeyCommand become a finished script you can read off a teleprompter.

![Script Studio with the script list on the left and the editor on the right](images/script-studio-1.png)

---

## What it is

Script Studio lists every reel script in your workspace and gives you a clean editor for each one, plus a built-in **teleprompter** so you can record without juggling another app. Scripts arrive here from two places:

- **Content Lab ideas** — when you click **Write script** on a kept idea.
- **Competitor reel teardowns** — when you click **Generate script** on a competitor reel.

You can also edit any script freely once it's here.

## Why it matters

A great idea is worthless until it's a script you can actually say to camera. Script Studio removes the friction between "I have a concept" and "I'm recording" — including the teleprompter that usually sends people to a separate tool.

---

## The layout

- **Left column — your scripts.** Every reel script, newest first. Each row shows the title, a small badge for where it came from (an **Idea** or a **Competitor** reel), its status, and how long ago it was created. Click a script to open it.
- **Right column — the editor.** The selected script's **title** and **body**, plus the action buttons.

---

## How to use it

### Edit a script

1. Click a script in the left list to open it.
2. Edit the **Title** and the **Script** body. The body is a plain text area built for writing what you'll say.
3. Click **Save**. (If you've made changes, you'll see an "Unsaved changes" note until you do.)

![editing a script's body in the editor](images/script-studio-2.png)

### Run the teleprompter

1. With a script open, click **Teleprompter**.
2. An auto-scrolling overlay opens with your current script text — read it straight off the screen while you record.
3. Close the teleprompter when you're done.

The teleprompter always uses the text currently in the editor, so tweak a line and re-open it to see the change immediately.

![the teleprompter overlay scrolling a script](images/script-studio-3.png)

### Generate a script (from elsewhere)

You don't create scripts from scratch in a blank file — you generate them where the idea lives:

- From a **kept idea** in [Content Lab](./content-lab.md) → **Write script**.
- From a **competitor reel** in [Competitors](./competitors.md) → **Generate script**.

The new script appears in the Script Studio list automatically.

### Take a script live

When a script is ready, use **Open in Drafts** (top-right of the editor) to jump to [Drafts](./drafts.md), where you can approve it and, if it's set up to publish, push it out.

---

## Tips

- **Generate, then refine.** The generated draft is a strong starting point — read it out loud once and trim anything that doesn't sound like you.
- **Use the source badges to triage.** "Competitor" scripts are adapted from a proven reel; "Idea" scripts are fresh concepts. Knowing the origin helps you decide how much to trust the angle.
- **The teleprompter reflects your latest edits.** No need to save before opening it for a quick read-through — but do save before you walk away.
- **Keep titles descriptive.** A clear title makes the left-hand list easy to scan when you've got a backlog of scripts.
